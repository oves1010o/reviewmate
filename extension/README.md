# 리뷰메이트 네이버 연동 확장프로그램

네이버는 스마트플레이스/스마트스토어 리뷰를 읽고 답글을 다는 공식 API가 없어서,
로그인된 네이버 세션(쿠키)이 필요합니다. 이 확장프로그램은 **사용자 본인 브라우저에
로그인된 네이버 세션**을 리뷰메이트 서버로 안전하게 전달하는 역할만 합니다.

## 동작 방식

1. 사용자가 자기 크롬에서 평소처럼 `naver.com`에 로그인
2. 리뷰메이트 대시보드 → "네이버 계정 연동" → **연동 코드 발급** (6자리, 10분 유효)
3. 이 확장프로그램 아이콘 클릭 → 연동 유형 선택(스마트플레이스/스마트스토어) → 코드 입력 → "연동하기"
4. 확장프로그램이 `naver.com` 쿠키를 읽어 `POST /api/extension/connect` 로 전송
5. 서버는 코드로 회원을 식별해 해당 회원의 헤드리스 브라우저 세션에 쿠키를 주입

서버에는 가짜 화면(Xvfb)이나 화면공유(VNC)가 전혀 필요 없습니다.

## 설치 (개발자 모드 / 미심사 배포)

1. 크롬 → `chrome://extensions`
2. 우측 상단 "개발자 모드" 켜기
3. "압축해제된 확장 프로그램을 로드합니다" → 이 `extension/` 폴더 선택

## 파일

- `manifest.json` — 권한(`cookies`, naver.com / reviewmate 호스트) 선언
- `popup.html` / `popup.js` — 연동 코드 입력 UI + 쿠키 전송 로직

## 배포 시 주의

- `popup.js` 의 `SERVER` 상수가 실제 서비스 도메인과 일치해야 합니다.
- 정식 배포하려면 Chrome 웹스토어 등록(심사) 또는 조직 정책 배포가 필요합니다.
